# 即梦图片下载器 (Jimeng Image Downloader)
一个轻量级 Chrome/Edge 浏览器插件，在网页图片上悬浮显示下载按钮，支持 `.webp` / `.png` / `.jpeg` / `.jpg` 格式图片一键下载。

## 功能特性

- 🖼️ **自动检测**：自动扫描页面上的 webp/png/jpeg/jpg 图片
- 📌 **悬浮按钮**：鼠标悬停图片时，右上角显示下载按钮
- ⬇️ **一键下载**：点击按钮直接下载到浏览器默认下载目录
- 🔄 **动态支持**：支持动态加载的图片（无限滚动、懒加载等）
- 🎯 **智能过滤**：只对大于 80x80 像素的图片显示按钮，避免误触小图标
- 📛 **自动命名**：从 URL 提取原始文件名，冲突时自动重命名

## 安装方法

### Chrome / Edge

1. 打开浏览器，地址栏输入 `chrome://extensions/`（Edge 为 `edge://extensions/`）
2. 打开右上角的 **「开发者模式」**
3. 点击 **「加载已解压的扩展程序」**
4. 选择本插件目录（`jimeng-image/` 文件夹）
5. 安装完成！插件图标会出现在浏览器工具栏

## 使用方法

1. 打开任意包含图片的网页
2. 将鼠标悬停在 `.webp` / `.png` / `.jpeg` / `.jpg` 格式的图片上
3. 图片右上角会出现一个 **「下载」** 按钮
4. 点击按钮，图片将自动下载到浏览器的默认下载目录
5. 按钮会显示「已下载」提示，确认下载成功
